PROFILE — MOCK DATA (no API)

The profile screen intentionally uses MOCK data, no network request.

Where is it defined?
  lib/features/profile/models/profile_model.dart   (data model)
  lib/features/profile/provider/profile_provider.dart (Riverpod Provider)

Example mock payload (hard-coded):
  {
    "name": "Munana Hori",
    "email": "munana.hori@example.com",
    "avatarUrl": "https://i.pravatar.cc/300?img=12",
    "location": "Bujumbura, Burundi",
    "memberSince": "January 2024"
  }

Extra numbers shown on the screen (Favorites / In cart / Orders) are
derived live from the favoritesProvider and cartProvider.
